# Employee Leave Management System

A comprehensive Full Stack web application designed to streamline the process of leave applications, manager approvals, and reimbursement requests within an organization.

## 🚀 Key Features

*   **Role-Based Access Control (RBAC):** Distinct dashboards and capabilities for Employees, Managers, and Admins.
*   **Employee Portal:** 
    *   Apply for leaves (Sick, Casual, Annual, etc.).
    *   Track leave history, statuses, and available balances.
    *   Submit reimbursement requests.
*   **Manager Portal:** 
    *   Review and approve or reject leave applications from reporting employees.
    *   Monitor team attendance and availability.
*   **Admin Dashboard:** 
    *   Manage user accounts (Add, Edit, Delete, change roles).
    *   System-wide oversight for all leaves and reimbursements.
*   **Secure Authentication:** JWT-based protection for all API endpoints and routes.
*   **Responsive UI:** Beautiful, mobile-friendly interface built with modern React patterns and Tailwind CSS.

## 🛠️ Technology Stack

**Frontend:**
*   React.js (with Vite)
*   Tailwind CSS (for styling and responsiveness)
*   React Router DOM (for client-side routing)
*   Lucide React (for icons)

**Backend:**
*   Node.js & Express.js
*   MongoDB & Mongoose (NoSQL Database)
*   JSON Web Tokens (JWT) for Authentication
*   Bcrypt.js (for password hashing)
